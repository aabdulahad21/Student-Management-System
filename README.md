# Student Management System

A web-based student management application developed using HTML, CSS, and JavaScript. The application provides an interactive interface for managing student information and performing operations such as grade calculation, sorting, filtering, and form validation.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Features

- Add and manage student information
- Edit student records
- Delete student records
- Calculate student grades
- Sort students based on relevant criteria
- Filter students by grade
- Client-side form validation
- Interactive user interface using JavaScript
- Dynamic updates using DOM manipulation

## Project Structure

- **HTML** – Defines the structure of the application
- **CSS** – Provides styling and layout
- **JavaScript** – Implements application logic, validation, calculations, filtering, sorting, and DOM manipulation

## Getting Started

### Prerequisites

A modern web browser such as Google Chrome, Microsoft Edge, or Mozilla Firefox.

### Running the Project

1. Clone the repository.

2. Open the project folder.

3. Open the main HTML file in a web browser.

4. Use the interface to add, edit, filter, sort, and manage student records.
