About This Project

This is a Student Dashboard developed as a mini project. It allows users to manage student records including adding, editing, deleting, searching, sorting, and filtering students.

Features:

  • CRUD operations on student data
  • Grade calculation
  • Statistics dashboard
  • Course module
  • Login system

Technologies Used:

  • HTML
  • CSS
  • JavaScript
  • LocalStorage
